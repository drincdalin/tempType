# tempType

conversor de temperatura, C <-> F. al 3 lea proiect pe care l-am facut in timp ce invat Js.

## demo

deschizi `index.html`, bagi o valoare, alegi directia, apesi submit. atat.

## stack

- html + css + js vanilla
- font: Source Code Pro de la google fonts
- tema dark (still monkeytype <b>again</b>), un singur accent rosu (`hsl(10, 97%, 45%)`)

## cum merge

- `Celsius → Fahrenheit`: `temp * 9/5 + 32`
- `Fahrenheit → Celsius`: `(temp - 32) * 5/9`

rezultatul apare sub buton, rotunjit la o zecimala.
